# Lokaliserade manualsidor

`wifi-analyzer.1` är den engelska originalmanualen. Lokala manualer placeras
i en katalog med språkets POSIX-namn, exempelvis `sv/wifi-analyzer.1`.

`po4a.cfg` anger de språk som ska få översättningskataloger när po4a används.
Den svenska manualen installeras direkt av både Debian- och RPM-paketeringen.
